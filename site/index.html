원문과 조사 문서

저장소의 Markdown 문서다. 링크는 GitHub에서 열린다.

  • 디지털포용법 통합 보고서 원문 (GitHub에서 열림) docs/digital-inclusion-analysis.md

    분석 페이지의 원문. 표와 출처 링크, 재현 명령을 모두 담았다.

  • 접근성 도구 아이디어 (GitHub에서 열림) docs/ideas.md

    도구 아이디어 28개와 하위 제안, 공통 근거와 조건별 우선순위.

  • 접근성 조사 문서 홈 (GitHub에서 열림) docs/README.md

    장애인 디지털 이용 환경, 민간 웹 접근성 법제, 연표와 출처 검증 노트.

  • 분석 재현 안내 (GitHub에서 열림) analyses/digital-inclusion/README.md

    입력 CSV, 분석 코드, 기계 판독용 결과와 실행 명령.
