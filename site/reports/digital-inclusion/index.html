01

자료 범위와 정책 시점

원문 §1 (GitHub에서 열림)

자료마다 관측 단위가 다르다. 검증 모델 수, 설치 기기 수, 납품요구 수, 이용자 연간 지수를 하나의 패널로 합치지 않고 각각 분석했다.

  • 계층·집계 × 연도 상대지수

    KOSIS 디지털정보격차 4개 통계표

    2014~2025년 240개 값. 주 비교는 2016~2025년 200개.

  • 공표 평균

    NIA 공식 조사 보고서

    디지털정보화 2021~2025년 100개 값(KOSIS와 대조용), 민간 웹 접근성 2019~2025년 7개 값.

  • 기기 기록

    행안부 무인민원발급기정보

    2026-10-03 수집, 고유 기기 기록 5,803건. 사용 여부와 접근성 기능 제공 표시.

  • 등록 행 · 납품요구 행

    조달청 나라장터쇼핑몰 품목정보

    2025-01~2026-09 등록 397행, 납품요구 상세 1,494행.

  • 검증 모델

    과거 NIA 우선구매 검증 목록 집계

    2026-09-30 기록의 771개 모델에 관한 집계 14개. 이번에 다시 수집하지 못했다.

  • 보류

    NIA 배리어프리 키오스크 위치 API

    사용자 결정으로 조회를 보류해 이번 분석에 넣지 않았다. 서비스 번호 15157403.

보고서의 디지털정보화 100개 값은 KOSIS와 대조하는 자료이므로 240개와 합쳐 독립 관측 수로 세지 않는다. 조달청·행안부·KOSIS는 모두 실제 인증과 수집을 마쳤다. 여기서 ‘전체 수집’은 명시한 조회조건에서 API가 반환하는 자료를 모두 받았다는 뜻이며, 현장의 모든 기기나 전체 시장 거래를 포괄한다는 뜻은 아니다.

디지털포용법은 2026-01-22 시행됐다. 그러나 모든 접근성 의무가 이날 새로 생긴 것은 아니다. 제조·임대 의무, 설치·운영 의무, 민간 웹·앱의 노력의무를 구분해야 한다. 검증 제품 모델 수 역시 법 전체의 효과를 대표하지 않는다. 아래 번호는 5장 조달 차트의 표식 번호와 같다.

02

이용자 측의 시행 전 기준선

원문 §2 (GitHub에서 열림)

모든 집단의 종합 공표지수가 시행 전부터 높아졌다. 그래서 2026년 값이 오르더라도 그 전체를 법 효과로 돌릴 수 없다.

각 지수는 해당 연도 일반국민을 100으로 둔 상대 수준이다. 100점 만점의 성공률도, 100을 상한으로 하는 점수도 아니며 변화 단위는 지수 포인트다. 일반국민의 수준이 움직여도 상대지수가 달라질 수 있으므로 취약계층의 절대 능력이 같은 폭으로 높아졌다고 해석하지 않는다. 취약계층 평균은 인구 규모를 고려한 가중평균이며, 독립된 다섯 번째 조사집단으로 취급하지 않는다.

왜 2016년부터인가 네 통계표의 주석에 따르면 2016년부터 기존 정보화·스마트정보화 지표를 디지털정보화 지표로 통합했고, 고령층 기준도 만 50세 이상에서 만 55세 이상으로 바뀌었다. 그래서 주 비교는 2016~2025년 200개 값으로 제한하고 2014~2015년 40개 값은 원자료에 보존했다. 아래 변화는 조사구성 변화를 보정하지 않은 공표값의 차이다.

장애인 역량의 2016→2021 차이는 +25.1, 2021→2025 차이는 +2.1 지수 포인트다. 길이가 다른 기간이고 표본·일반국민 분모·정책 기여를 분리하지 않았다. 특정 시점에 개선 속도가 유의하게 바뀌었다는 검정은 하지 않았다.

조사 대상의 범위 2025년 보고서의 장애인 조사 대상은 7~69세의 지체·뇌병변·시각·청각/언어 장애인이다. 전체 장애인이나 70세 이상을 대표하지 않는다. 반올림된 집계값으로 차이를 계산했으며 통계적 유의성은 판정하지 않았다.
03

민간 웹 접근성의 시행 전 공표점수

원문 §3 (GitHub에서 열림)

민간 웹 접근성 평균은 2019년 53.7점에서 2025년 70.4점으로 높아졌다. 2026년 3월에 발표된 결과라도 조사연도는 2025년이다.

2025년 표본은 8개 업종의 민간 웹사이트 1,000개이며 PC 환경에서 평가했다. KWCAG 평가기준·배점·표본 변화의 영향을 분리하지 못했으므로 기간 전체를 같은 척도의 추세로 단정하지 않는다. 공공 웹·모바일 앱·키오스크 결과로 일반화할 수도 없다. 이용자·웹 연간 통계에는 시행 후 관측이 없으며, KOSIS의 최종수정일이 2026년인 셀도 조사연도를 기준으로 분류했다.

04

무인민원발급기의 현재 접근성 기능

원문 §4 (GitHub에서 열림)원문 §10 (GitHub에서 열림)

사용 중으로 기재된 5,800건 중 562건에 휠체어 사용자 조작이 불가능하다고 표시돼 있다. 촉각 전자모니터 제공 표시는 1,550건(26.72%)이다.

불가능 표시는 현장 확인 후보다 실제 접근 동선, 높이, 작동 여부, 보조인력은 확인하지 않았다. 촉각 모니터가 없다고 위법·부적합 기기로 판정할 수 없으며, 여덟 기능을 합쳐 법 준수율을 만들지도 않는다.

분모와 수집 완전성

분모는 기기 고유키(OPN_ATMY_GRP_CD + MNG_NO)가 확인되고 사용 여부가 ‘사용’으로 기재된 기록이다. 전체 5,803건 중 나머지 3건은 ‘미사용’이며 사용 여부 미상은 0건이다.

첫 페이지 방식 수집에서는 고유키가 5,768개뿐이었다. 페이지 경계에서 35행이 반복돼 단순 중복 제거로는 누락을 배제할 수 없었다. 그래서 230개 개방기관으로 나누고, 100건을 넘는 기관은 겹치지 않는 갱신시각 구간으로 나눠 다시 수집했다. 최종 231개 분할의 합계·고유키 수·API 총건수가 모두 5,803으로 일치했다. 분할 부모를 포함한 응답 232개의 해시와 조건도 대조했다. 다만 여러 요청에 걸친 수집이므로 한 시점의 트랜잭션 스냅샷은 아니다.

행정구역 개편 12 접두어 기록 601건의 원주소를 보면 600건의 첫 토큰은 ‘전남광주통합특별시’, 1건은 ‘강진군’이었고 모두 같은 광역 기관코드가 기재돼 있었다. 행안부는 2026-07-01 전남·광주 통합 출범을 안내한다. 과거의 17개 시도 명칭표를 그대로 적용하면 잘못 분류할 수 있다. 관측한 시군구 코드 259개도 코드값의 종류 수이지 현재 자치단체 수가 아니다.
수정·갱신일은 설치일이 아니다 최종수정시점은 2023-07-14~2026-09-30이고, 마지막 수정이 수집일보다 365일 넘게 앞선 사용 기록은 23건이다. 데이터갱신시점은 2026-01-16~2026-10-01이다. 둘 다 설치일·기능 도입일이 아니므로 시행 전후 비교 축으로 쓰지 않았다. 과거 기능·교체 이력이나 반복 스냅샷이 필요하다.
05

시행 전후 조달 요청의 흐름

원문 §5 (GitHub에서 열림)

증명발급기·무인안내시스템의 같은 2~9월 납품요구 순증은 2025년 872대에서 2026년 597대로 31.5% 감소했다. 법정 시행일과 같은 1/22~9/30끼리 비교하면 930대 → 716대, 23.0% 감소다.

품목 범위. ‘무인민원발급기’라는 자연어 검색만으로는 해당 품목을 찾지 못했다. 실제 응답의 상위 분류 컴퓨터키오스크(43211514)를 수집하고, 증명발급기(4321151401)·무인안내시스템(4321151402)을 주 분석 범위로 삼았다. 버스및차량정보안내장치는 상호작용 키오스크와 같게 취급하기 어려워 뺐다. 범위는 자료를 탐색한 뒤 정했으므로 사전 등록 분석이 아니다.

주 지표는 접수월 기준 납품요구 순증이다. 최초 요구와 이후 변경·취소의 수량·금액을 부호대로 합산한다. 3대 요구 후 2대를 추가하면 5대, 3대 요구를 모두 취소하면 0대다. 구매 요청·변경 기록이므로 실제 납품 완료, 설치, 집행액, 접근성 검증을 측정하지 않는다.

같은 2월부터 9월까지 비교

후속 자료의 우선순위는 기기별 기능·교체 이력, NIA 제품 최초 검증·갱신·철회 이력, 시행 당시 제조사 규모·역할이다. NIA 위치 API(15157403)의 조회는 사용자가 재개를 요청할 때까지 보류하며 제품 검증 이력 확보와 구분한다. 후속 자료 상태는 docs/work/W-004-main-history-data.md에 기록한다.

보고서와 KOSIS 출처를 대조한 결과

원문 §8 (GitHub에서 열림)

NIA 보고서의 디지털정보화 100개 값을 KOSIS와 같은 지표·집단·연도·단위로 대조했다. 99개가 일치하고 1개 셀에서 0.1포인트 차이가 났다.

2025 NIA 보고서 본문 23쪽 표3(PDF 49페이지)을 화면으로 다시 확인했고 텍스트 추출도 94.8로 같았다. KOSIS는 94.9이고 해당 셀의 최종수정일은 2023-06-26이다. 2021년 조사 보고서의 현재 공식 첨부파일은 농어민 접근지수를 2021년 94.9로 표시해 KOSIS와 일치한다. 그러나 2025년 보고서의 과거 값에 대한 공식 정정 공지는 찾지 못했고, 현재 첨부파일이 최초 게시 당시와 같은지도 검증하지 않았다.

기존 보고서 CSV를 고치지 않고 양쪽 출처를 보존했다. 장기 비교는 KOSIS 계열만 쓰며 보고서 계열과 이어 붙이지 않는다. 이 차이는 2021년을 포함한 농어민 접근지수 변화량에 0.1포인트 영향을 주지만, 2016→2025 끝점 비교와 2025년 수준에는 영향을 주지 않는다. 별도로 보고서 내부의 활용 원점수 불일치도 확인해 원점수 역산을 빼고 공표 상대지수만 사용했다.
