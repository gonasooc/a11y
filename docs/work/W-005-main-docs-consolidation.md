### 배경과 범위

아이디어 문서는 작성 차수별 반복 전제·근거를 통합하고 주제별로 읽도록 구성한다. 분석은 수집 단계별 보고서 대신 현재 확인된 결과·기간·자료 범위와 한계를 한 문서에서 읽도록 구성한다.

- 2026-10-03 — 아이디어 1~28의 식별자, 12번의 세 하위 도구, 작은 아이디어 10개와 조건별 시작 순서를 보존한다. 기획 가설을 확정된 제품 정책으로 바꾸지 않는다.
- 2026-10-03 — 분석 보고서에서는 보고서/API 출처의 차이, 조사·수집 시점, 모집단·분모, NIA 과거 목록 집계의 재수집 한계와 위치 API 보류 상태를 유지한다.
- 2026-10-03 — 기존 여섯 문서를 임시 작업 경로에 보관해 대조한다. 통합 검증 후 이전 파일은 통합 문서로 대체하며, 저장소에 별도 archive 폴더나 중복 본문은 만들지 않는다.
- 2026-10-03 — 분석 코드·입력 CSV·출처 메타데이터·계산 출력은 변경하지 않는다. 실행 안내·작업 기록에서 문서 링크를 고치는 것은 통합에 필요한 범위로 한정한다.
- 2026-10-03 — 아이디어는 상단 28개 바로가기 표와 다섯 주제의 같은 카드 형식으로 묶었다. 공통 근거와 출처는 카드 뒤로 옮겼고, 공익 감시·자료 확보와 기관 협력 제품 실험의 우선순위를 구분했다. 비용 가설·중단 조건·측정 분모·당시 정성 평가도 보존했다.
- 2026-10-03 — 분석은 현재 결론부터 자료·정책 시점, 이용자·웹 기준선, 기기·지역 현황, 조달 흐름, 과거 검증 목록, 한계·출처 대조·재현 순서로 재구성했다. 중복된 기준선 표는 연도 열을 합쳐 고유 값을 유지했다.
