## 현재 상황

웹 보고서([site/reports/digital-inclusion/index.html](../../site/reports/digital-inclusion/index.html))를 비장애인 독자가 장애인의 인터넷 이용 실태, 디지털포용법 시행 전후, 법의 한계를 한눈에 파악할 수 있게 개편했다. 2026-10-12 질의응답으로 정한 13개 결정을 모두 구현해 `6e64a45`로 커밋·푸시했고, 공개 주소에 배포해 확인했다. 남은 것은 비장애인 독자 테스트와 첫 화면 구성 결정이다.

- 완료 조건: 공개 주소의 보고서가 아래 결정을 따른다. 생성 스크립트 검사, axe-core, 320px·390px·1440px 화면 확인을 통과한다. 비장애인 독자 2~3명이 첫 화면만 1분 보고 핵심 세 가지를 말할 수 있다.
- 사람이 판단할 사항: 독자 테스트 진행(사용자, 질문지는 아래). 첫 화면을 지금처럼 ‘제목 → 한 문장 설명 → 한눈에 보기’로 둘지, 오른쪽에 가장 강한 숫자 하나(접근 98.1 대 역량 77.0)를 큰 그림으로 둘지.

## 진행과 판단

### 배경과 범위

사용자 요청(2026-10-12): 디지털포용법 분석 원문과 이를 바탕으로 만든 웹 보고서를 더 실질적으로 자료를 한눈에 파악할 수 있는 문서로 바꾼다. 비장애인은 장애인의 인터넷 이용 실태를 잘 모른다. 디지털포용법 시행 전후 데이터 분석과 법의 한계를 통해 비장애인이 장애인 인터넷 이용 실태를 파악할 수 있게 구성한다.

### 중요한 시도와 결정

- 2026-10-12 — 진단(사실): 기존 보고서 10개 절 가운데 이용자를 다루는 절은 하나이고, 그마저 장애인 전체의 상대지수 4개뿐이다. 실태 재료는 [docs/digital-inclusion/environment.md](../digital-inclusion/environment.md), 법의 한계는 [docs/digital-inclusion/law.md](../digital-inclusion/law.md)에 있다. 기존 보고서의 ‘한계’는 대부분 분석의 한계다. 시행 후 이용자 통계는 아직 없다(최신은 2026년 3월 발표된 2025년 조사).
- 2026-10-12 — 질의응답으로 확정한 결정(모두 사용자 선택):
  1. 내용: 이용 실태 조사(지금은 docs/digital-inclusion/environment.md)와 법 구조 조사(지금은 docs/digital-inclusion/law.md)를 본문 중심에 둔다. 공공데이터 분석은 시행 전후 근거로 쓰고, 조달 분해·검증 목록·출처 대조·재현은 분석 노트로 접는다.
  2. 근거: 본문 숫자는 A·B 등급만 쓴다. C 등급은 ‘보도에 따르면’을 붙인 맥락 문장으로만 쓴다. 가져온 숫자는 출처·기준일·등급과 함께 데이터 파일로 정리해 생성 스크립트가 본문 숫자를 대조한다.
  3. 첫 화면: ‘한눈에 보기’ 세 가지를 실태 → 법의 한계 → 효과 순서로 둔다. 효과는 ‘아직 판단하기 이르다’로 쓴다.
  4. 목차: 독자 질문 6개(누구의 이야기인가, 인터넷을 얼마나 쓰나, 어디서 막히나, 법은 무엇을 바꾸고 무엇을 못 바꾸나, 시행 후 지금까지 보이는 것, 언제 효과를 알 수 있나)와 접힌 분석 노트.
  5. 지수 표현: 일반국민 100을 기준선으로 그은 막대. 처음 나올 때 ‘점수나 비율이 아니라 같은 해 일반국민을 100으로 둔 상대 수준’이라고 풀이하고 ‘점’·‘%’를 쓰지 않는다.
  6. 5절: 발급기 현황, 구매 요청, 검증 모델을 숫자 하나와 ‘무엇을 뜻하지 않는지’ 한 줄로 쓴다. 구매 요청 감소는 ‘접근성이 나빠졌다는 근거로 볼 수 없다’로 쓴다. 차트는 구매 요청 비교 하나.
  7. 4절: 장애인차별금지법과 디지털포용법이 겹친 구조, 디지털포용법이 바꾸는 것과 못 바꾸는 것, 집행 실적 세 가지. 각 내용의 근거 법(예: 필수 편의 6→2가지는 장애인차별금지법 시행령)을 표시한다. 판례·입법 동향은 한 줄과 링크.
  8. 3절: 장애유형별 ‘한 장면’ 카드 다섯 장(시각·저시력·청각·지체·발달). A·B 사실만 쓰고 실명 발언 인용과 지어낸 인물은 쓰지 않는다.
  9. 차트: 본문 6개(일반국민 100 기준선 막대, 장애인 종합 추이와 시행일 표시, 웹 항목별 준수율, 발급기 기능 현황, 의무 적용 일정, 구매 요청 비교). 나머지 기존 차트는 접힌 분석 노트 안에서 펼칠 때 그린다.
  10. 문체: 한다체 유지, 쉬운 말 원칙(용어 첫 등장 풀이, 한 문장 한 정보, 숫자마다 연도·단위).
  11. 제목: ‘장애인의 인터넷, 어디서 막히나’, 부제 ‘디지털포용법 시행 전후로 본 이용 실태와 법의 한계’. 첫 화면의 ‘판단 불가’ 판정 카드를 빼고 6절로 옮긴다. 주소는 유지한다.
  12. 근거 연결: 머리글은 ‘전체 목록’만. 절마다 ‘이 절의 근거’ 링크, 바닥글에 근거 문서 세 개. 숫자별 원출처 링크는 유지한다.
  13. 완료 기준: 쉬운 말 점검표와 자동 검사, 비장애인 독자 2~3명 테스트(사용자 진행, 질문지는 에이전트 작성).

## 독자 테스트 질문지

대상은 장애인의 인터넷 이용을 따로 공부한 적 없는 비장애인 2~3명이다. 휴대폰이나 노트북에서 보고서 첫 화면만 1분 보여 준 뒤 화면을 가리고 묻는다. 보기를 주지 않고, 답을 고쳐 주지 않는다.

1. 이 페이지가 말하는 것을 세 가지로 말해 주세요.
2. 가장 헷갈렸거나 잘못 읽힐 것 같은 숫자나 말은 무엇이었나요?
3. 장애인이 인터넷을 쓸 때 가장 큰 문제가 무엇이라고 읽혔나요?

기록할 것: 첫 화면에서 본 기기와 화면 폭, 답한 내용(그대로), 세 가지 가운데 맞힌 항목 수(실태·법의 한계·효과), 헷갈린 표현. 한 사람이라도 ‘98.1%의 장애인’처럼 지수를 비율로 읽거나 ‘법 때문에 접근성이 나빠졌다’고 읽으면 해당 문구를 고친다.

완료할 때는 완료 조건과 검증 결과를 확인하고, 후속 작업이 있으면 해당 작업으로 연결합니다. 문서는 삭제하지 않습니다.
