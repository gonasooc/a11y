## 현재 상황

W-011에서 만든 KOSIS 등록 통계 추이(2007~2025)와 2012~2016년 방송 실적을 웹 보고서에 넣었다(2026-10-17 사용자 요청). 1절에 그림 1(등록 청각장애인 65세 이상·미만), 2절에 그림 3(2012~2016년 한 가지 이상 미달)을 더하고 나머지 그림 번호를 2·4·5·6으로 바꿨다. 생성 검사·axe·세 폭 화면 확인을 통과했다. 사용자 승인으로 W-011 변경과 함께 `ba0d5b5`로 커밋했고 사용자가 푸시했다. 배포와 공개 주소의 화면·axe, GitHub 문서 링크·앵커를 확인해 완료로 바꿨다.

- 완료 조건: 보고서 1절에 등록 청각장애인의 나이별 추이, 2절에 2012~2016년 미달 사업자 그림이 들어간다. 본문 숫자는 모두 생성 스크립트로 대조하고, `node site/scripts/generate.mjs --check`, axe-core 위반 0, 320·390·1440px 화면 확인을 통과한다. 허브 항목의 날짜를 맞춘다.
- 사람이 판단할 사항: 없음.

## 진행과 판단

### 배경과 범위

- 2026-10-17 — 사용자 요청: "보고서에 등록 통계 추이나 2012~2016년 실적을 넣어줘". 두 가지를 모두 넣는다(에이전트 판단). 2012~2016년은 목표 기준이 달라 2017년 이후 그림과 잇지 않고 따로 그린다(W-011의 분석 기준).

### 중요한 시도와 결정

- 2026-10-17 — 작업 문서 생성.
- 2026-10-17 — **그림 1(1절, 선 그래프)**: 등록 청각장애인을 65세 이상과 65세 미만 두 선으로 그렸다(만 명, [site/assets/js/chart/line.js](../../site/assets/js/chart/line.js) 그대로 사용). 총계 한 선보다 '늘어난 쪽이 65세 이상'이 바로 보이고, 1절의 '가장 많이 필요한 사람은 나이 든 청각장애인' 문장과 맞는다(에이전트 판단). 시각장애인은 본문 한 문장과 표의 열로만 둔다. 이를 위해 [analyses/media-access/registry_analyze.py](../../analyses/media-access/registry_analyze.py)에 `age_under65`·`age_unknown` 열을 더했다.
  - 본문 비교는 2015년을 기준으로 썼다. 2007~2014년은 100세 이상 구간이 공표되지 않아 2007년 65세 이상이 만 명 단위(10.6 대 10.7)와 비율(52.3 대 52.4)에서 표기가 갈릴 수 있기 때문이다. 그림은 2007년부터 그리고, 표 설명에 공표되지 않은 89~241명을 적었다.
  - [site/reports/media-access/report.config.mjs](../../site/reports/media-access/report.config.mjs)가 KOSIS 2025년 청각·시각 인원과 65세 이상 비율을 1절 첫머리의 보건복지부 값(조사 문서 숫자)과 대조하고, 다르면 생성이 멈춘다.
- 2026-10-17 — **그림 3(2절, 세로 막대)**: 2012~2016년 '한 가지 이상 목표에 못 미친 방송사'. 보도자료 집계와 모두 같은 값이다. 2012년은 지상파만 평가해 기존 부분 막대 표시(옅은 파랑 `--before`, 값 뒤 별표)를 쓰고 그림 아래에 뜻을 적었다. 2017년 이후 그림 2와 기준이 달라 그림을 나누고, 그 이유(사업자별 단계 목표, 2016년 SO 폐쇄자막 목표 30~70%)를 본문에 썼다.
  - 2절의 기존 2012년 문장(조사 문서 숫자, B)은 그대로 두고, 생성 설정이 원자료 계산(화면해설 미달 23곳, 평가 대상 50곳)과 같은지 대조하게 했다.
  - 보도자료 집계와 계산이 하나라도 다르면 생성이 멈추게 했다(본문이 '모두 같다'고 쓰기 때문).
- 2026-10-17 — 검토 반영: 그림 2(폐쇄자막만)와 그림 3(세 가지 중 하나라도)은 세는 방식도 달라, 목표 기준과 함께 이 차이를 2절 본문에 밝혔다. 1절 새 문단 첫머리에 출처 이름(KOSIS 등록 통계)을 붙였다([docs/design.md](../design.md)의 '숫자마다 원출처나 조사 이름' 기준). 숫자는 바뀌지 않아 생성 검사만 다시 했다(통과, 100곳).
- 2026-10-17 — 머리 설명·한 문장 설명을 '편성 실적(2012~2025년)과 법령, 등록 통계와 이용자 조사'로, 머리의 '조사·분석 기준'을 2026-10-17로 바꿨다. 1·2절 근거 줄에 KOSIS 통계표와 분석 §2.8을, 분석 노트 01에 두 자료의 처리 방법을 더했다. 허브 항목은 요약·태그('등록장애인 통계(KOSIS)')를 더하고 날짜를 2026-10-17로 바꿨다.
