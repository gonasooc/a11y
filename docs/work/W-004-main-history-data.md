# W-004 · 기기와 검증 제품의 과거 이력 확보

- 상태: 예정
- 최근 갱신: 2026-10-03
- 관련 문서: [docs/digital-inclusion-analysis.md](../digital-inclusion-analysis.md), [docs/work/W-003-main-additional-data.md](W-003-main-additional-data.md)

## 현재 상황

조달청·행안부·KOSIS에서 현재 가능한 인증 분석은 완료했다. 법 시행 전후의 실제 접근성 변화를 더 직접적으로 보려면 기기별 기능 변화, 제품 검증 이력과 시행 당시 제조사 정보가 필요하다. KOSIS의 네 표는 2025년까지여서 이후 연간 자료도 기다려야 한다.

**부분 보류:** NIA 배리어프리 키오스크 위치 정보 API(`15157403`)의 키 발급 경로 조사·연결·수집·분석은 사용자의 2026-10-03 요청으로 보류한다. 사용자가 재개를 요청하면 그때 이어간다. NIA 제품 검증 이력 등 다른 자료 확보 항목과 구분한다.

- 완료 조건: 확보 가능한 이력의 출처·관측 단위·기간·결측과 비교 설계를 점검하고 추가 분석 결과 또는 확보 한계를 기록한다.
- 사람이 판단할 사항: 기관별 자료 요청 방식·범위와 우선순위는 미정이다. 외부 요청이나 정기 수집을 설정한 상태는 아니다.

## 진행과 판단

### 배경과 범위

현재 행안부의 수정·갱신일은 설치일이 아니며, 조달 요청은 실제 설치·이용 가능성의 기록이 아니다. KOSIS 연간 상대지수와 이 자료를 기기 단위로 결합할 수도 없다. 추가 이력 없이 법의 인과효과를 계산하지 않는다.

### 중요한 시도와 결정

- 2026-10-03 — 사용자가 NIA 배리어프리 키오스크 위치 정보 데이터를 잠시 보류하기로 했다. 해당 API의 후속 조사·문의·연결·수집은 진행하지 않으며, 재개 조건은 사용자의 재개 요청이다. 확인된 연결 정보는 [docs/10-digital-inclusion-api-guide.md](../10-digital-inclusion-api-guide.md)에 남긴다.
- 2026-10-03 — 기기별 설치·교체·기능 변경·삭제 이력과 과거 스냅샷을 우선 후보로 남겼다.
- 2026-10-03 — NIA 최초 검증·갱신·철회, 제조사 역할과 시행 당시 기업규모가 필요하다. 현재 중소기업 표기로 중기업·소기업을 임의 분류하지 않는다.
- 2026-10-03 — KOSIS 새 연간 수치가 공표되면 기존 2016~2025 기준선과 정의·범위를 먼저 대조한다. 출처 간 차이가 난 2021 농어민 접근지수의 공식 정정도 후속 확인 사항이다.

### 검증

- 추가 이력 확보·기관 요청·정기 수집 — 미실행. 완료된 인증 수집은 W-002·W-003에 기록돼 있다.

### 세션 메모

- 2026-10-03 · Codex — 현재 API 세 종류의 분석 이후 남은 자료 공백을 분리했다. 재개 시 먼저 확보할 자료와 접근 가능한 경로를 확인한다.
- 2026-10-03 · Codex — 사용자 요청으로 NIA 위치 API만 보류 표시했다. 추가 API 호출·문의 발송·수집은 하지 않았다.
