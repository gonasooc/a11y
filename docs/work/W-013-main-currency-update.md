## 현재 상황

2026-10-27 사용자 요청으로 두 보고서와 근거 문서의 시점이 걸린 서술을 웹으로 다시 확인했다. 네 묶음으로 병렬 조사하고, 영향이 큰 주장은 원문을 다시 열었다. 보고 뒤 사용자가 "모두 수정 진행해"라고 지시했다. 발행 보고서에서 찾은 오류 한 건(영상 보고서의 영국 할당 '처음 두 해')을 고쳤다. 두 주제의 근거 문서도 갱신했다. 생성 검사, 링크 검사, 바뀐 페이지의 axe·세 폭 화면 확인을 통과했다. 커밋·공개, 데이터 갱신, 국정감사 후속이 남았다.

- 완료 조건: 확인된 오류를 고친다. 근거 문서의 바뀐 사실과 새 자료를 등급·출처와 함께 반영하고, 재확인 표의 시점을 갱신한다. 생성 검사, 링크 검사, 바뀐 보고서의 axe·세 폭 화면 확인을 통과한다. 데이터 갱신과 국정감사 후속은 남은 일로 연결한다.
- 사람이 판단할 사항:
  - 조달청·행안부 API 키를 다시 넣을 시점. 저장소에 `.env`가 없다. 10월분을 넣으려면 11월 초를 권한다.
  - NIA 검증 목록의 전체 갱신 방법. 사이트가 자동 요청을 막아, 사용자가 브라우저로 목록 페이지를 저장해 주는 방식 등이 필요하다.
  - 국정감사 후속(10-30 이후)을 누가 볼지.
