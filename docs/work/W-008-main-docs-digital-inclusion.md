웹 보고서 `site/reports/digital-inclusion/`이 참고하는 문서를 같은 이름의 `docs/digital-inclusion/` 폴더로 옮기고, 흩어져 있던 조사·분석 문서 일곱 개를 네 문서로 합쳤다. 저장소의 링크와 앵커를 모두 새 경로로 고쳐 링크 검사와 생성 스크립트 검사를 통과했고, `b700c2e`로 커밋·푸시했다. 배포된 공개 보고서의 GitHub 링크가 모두 새 경로와 앵커로 열리는 것을 확인해 완료했다.

- 완료 조건: `docs/digital-inclusion/` 아래 네 문서로 정리되고, 저장소 링크·앵커 검사에서 문제가 0건이며, 생성 스크립트 검사를 통과한다. 푸시 뒤 공개 보고서의 GitHub 링크가 새 경로로 열린다.
- 사람이 판단할 사항: 없음.
