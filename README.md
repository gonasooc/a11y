# a11y

접근성 도구와 데이터 분석을 하나씩 추가하는 저장소입니다. 향후 메인 페이지에서 각 도구와 분석 페이지로 이동하도록 구성합니다.

현재는 첫 번째 주제인 **디지털포용법 시행 전후 변화**의 데이터 분석을 진행합니다. 웹 화면 구현에 앞서 출처, 계산, 해석 범위와 후속 수집 계획을 정리했습니다.
